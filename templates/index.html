Theoretical Foundations & Viva Guide

Comprehensive explanation of DBSCAN concepts for college semester demonstration

What is DBSCAN?

DBSCAN stands for Density-Based Spatial Clustering of Applications with Noise. It is an unsupervised machine learning algorithm designed to identify clusters of arbitrary geometric shape in spatial data by detecting dense regions separated by regions of low point density.

What is Epsilon (eps)?

Epsilon (eps) specifies the radius of the spherical neighborhood surrounding each point in the feature space. Two points are considered neighbors if the Euclidean distance between them is less than or equal to eps.

What is min_samples?

min_samples is the threshold parameter defining the minimum count of neighboring points (including the candidate point itself) required inside the eps-neighborhood for a point to qualify as a Core Point.

What is a Cluster?

A Cluster is formed by a maximal set of density-connected points. Starting from any core point, all neighboring points within eps are included, expanding recursively across density-reachable nodes until boundary conditions are met.

What is Noise?

Noise (or Anomaly) consists of points that do not satisfy core point requirements and are not density-reachable from any core point. In scikit-learn, DBSCAN flags these isolated outliers with label -1.

Why DBSCAN for Game Anomaly Detection?

Unlike K-Means (which forces spherical clusters and assigns every point to a cluster), DBSCAN accommodates non-linear paths (walkways, corridors, objective sites) and naturally rejects density outliers. Unnatural teleports, speed hacks, and snap rotations fail density criteria and are automatically isolated.
